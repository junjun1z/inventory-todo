# GTNH ToDo

GT New Horizons 2.9.0 向けのクライアント専用 mod です。インベントリ画面の左に ToDo リストを表示します。

- 必要: NotEnoughItems（GTNH 同梱）
- サーバーへの導入は不要です（入っていないサーバーにも接続できます）

## 使い方

| 操作 | 内容 |
| --- | --- |
| 「+ メモ」 | メモ行を追加。日本語も入力可（Enter で確定 / Esc で取消） |
| 文字をクリック | メモを編集 |
| 「+ アイテム」 | 名前（日本語・英語）または `modid:name[:meta]` で検索して追加 |
| Alt+クリック | インベントリや NEI のアイテムを登録（設定で Ctrl / Shift に変更可） |
| NEI からドラッグ＆ドロップ | 登録 |
| アイテムを持ってパネルをクリック | 登録（持っている個数が目標数になる。アイテムは減らない） |
| 個数の上でホイール | 目標数 ±1（Shift ±16 / Ctrl ±64） |
| 個数をクリック | 目標数を入力 |
| 個数を右クリック | 今の所持数を目標数にする |
| アイコン左/右クリック | NEI のレシピ / 用途 |
| アイテムの上で NEI のキー | R / U など、NEI で設定したキーがそのまま使える |
| Shift+ホイール | 行の並べ替え |
| ヘッダーをドラッグ | 自由な位置へ移動 |
| 「追/左/自」ボタン | 配置の切替: インベントリ追従 → 画面左端 → 自由配置 |
| 「_」ボタン | 最小化（アイコンに未完了の件数を表示） |

- 所持数は自動で数え、`[32/64]` のように表示します。目標に達すると自動でチェックと打ち消し線が付きます。
- GT の機械や回路のメタ値・NBT はそのまま保存します。

## 保存場所

- リスト: `config/gtnhtodo/lists/<ワールド名>.json`（ワールド・サーバーごと）
- パネル位置: `config/gtnhtodo/ui.json`
- 設定: `config/gtnhtodo/gtnhtodo.cfg`

## ビルド

```
./gradlew build
```

`build/libs/gtnhtodo-<version>.jar` を `mods` フォルダへ入れてください。
